1. OVERVIEW & PURPOSE
--------------------------------------------------------------------------------
The Corporate Intelligence Search Engine is an enterprise-grade agent designed
to search, verify, and enrich Indian corporate entities. It accepts any Indian
Company Name or Corporate Identification Number (CIN) and returns clean, verified
statutory, leadership, digital contact, and social intelligence in a structured
table format with 0% data hallucination.


2. SYSTEM ARCHITECTURE (2-TIER DESIGN)
--------------------------------------------------------------------------------
The system is built on a high-performance 2-tier design:

[TIER 1] Local Database & Cache Engine (0 ms - 2s)
  • Persistent Cache: 'company_master_intelligence.csv' stores all verified
    enriched profiles for instant zero-latency retrieval.
  • Local MCA Database: Scans 3.2+ million registered Indian company records
    across 'cleaned_csv/' and 'main_csv/' using strict exact-match indexing.

[TIER 2] Single-Source Authoritative Live Enrichment (3s - 8s)
  • Invoked only when missing digital or statutory contact intelligence.
  • Each data category pulls strictly from its primary authoritative source.
  • Unverified, ambiguous, or foreign data is marked as "NOT_FOUND".

4. AUTHORITATIVE SOURCES OF TRUTH & RULES
--------------------------------------------------------------------------------
1. STATUTORY DATA (CIN, Capital, Address, State, Class, Date):
   • Source: Cleaned Local MCA Database ('cleaned_csv/').
   • Rule: Strict exact matching ('q == cin' OR 'q == legal_name' OR 'norm_q == norm_name').
   • Never adopts arbitrary CINs or addresses from search snippets.

2. DIRECTORS & KEY PEOPLE:
   • Source: Official MCA Filing Records via CIN.
   • Rule: Real DIN-holding directors from statutory filings. Never scrapes
     random or hallucinated names from web searches. If not found -> "NOT_FOUND".

3. OFFICIAL WEBSITE:
   • Source: DuckDuckGo whole-name brand queries.
   • Rule: 'is_candidate_website_valid' enforces:
     - Domain must contain ALL distinctive brand tokens (e.g. 'culmen' + 'exim').
     - Page content must explicitly contain the full company name.
     - Page must show verifiable Indian presence (India, +91, Pvt Ltd, state/city).
     - Obvious international sites with no Indian presence are strictly rejected.

4. BUSINESS EMAIL & CONTACT FORM:
   • Source 1: Verified Website Domain Email (e.g., 'contact@aivatika.com').
   • Source 2: Official MCA filing email (e.g., 'archit_singla@outlook.com').
   • Rule: Never adopts free/generic emails from third-party aggregators.

5. LINKEDIN & INSTAGRAM:
   • Source: Official website JSON-LD schema OR verified whole-name social search.
   • Rule: Slug/handle must match all distinctive brand tokens.
   • Rule: Rejects international suffixes ('international', 'global', 'usa', 'oficial').


5. OUTPUT SCHEMA (16 COLUMNS)
--------------------------------------------------------------------------------
 1. CIN                                    - Corporate Identification Number
 2. Company Name                           - Official Registered Name
 3. Company Registration Date              - Date of Incorporation (YYYY-MM-DD)
 4. Company Class                          - Private / Public
 5. Company Industrial Classification      - Business Category / NIC Code
 6. Company State                          - Registered State in India
 7. Company Address                        - Official Registered Office Address
 8. Authorized Capital                     - Authorized Share Capital (INR)
 9. Paidup Capital                         - Paid-up Share Capital (INR)
10. Company Website                        - Official Corporate URL
11. Company Email                          - Verified Business / Filing Email
12. Company Contact Form                   - Contact / Support Webpage
13. Employee Strength                      - Headcount range (if stated)
14. Key People (Director/CEO/Stakeholder)  - Official Directors & Founders
15. Company LinkedIn                       - Official LinkedIn Page URL
16. Company Instagram                      - Official Instagram Handle URL


6. HOW TO RUN
--------------------------------------------------------------------------------
A. Interactive Streamlit Web UI:
   powershell> python -m streamlit run app.py --server.port 8501
   • Open: http://localhost:8501
   • Search any company name or CIN.
   • Clean table presentation with zero data leakage or bulk download options.

B. Command Line Interface (CLI):
   powershell> python master_main.py --company "AIVATIKA"
   powershell> python master_main.py --company "CREDITECH SOLUTIONS PRIVATE LIMITED"
   powershell> python master_main.py --company "U51909HP2022PTC009552"
   • Use '--no-cache' flag to force a fresh live re-scrape.
